====================

   Local dependency closure:
   - agents/agent_config.py
   - agents/fixed_prior_ctde.py
   - environment/async_mult_intersection_env.py
   - environment/traffic_signal.py
   - tools/e6_flow_profiles.py

   - agents/adaptive_max_green.py

   - agents/rule_coordination.py
   - nets/2x2-grid/2x2.net.xml
   - five route files listed in tools/eval_enhanced_actuated_r1.py

   - utils/metrics_schema.py

   The schema constants and CSV writer are constrained by the included unit tests
   and match the archived train, evaluation, paired, and intermediate CSV headers.

   Python dependencies: matplotlib, numpy.

External runtime dependencies
=============================

- Eclipse SUMO binary and SUMO_HOME for simulation.
- traci and sumolib Python packages.
- PyTorch for the CTDE agent.
- gym for environment spaces.

Packaging-environment limitations
=================================

- The SUMO binary was not available, so simulator execution was not tested.
- The packaging interpreter was Python 3.14.7; the recommended reproduction
  environment is Python 3.10/3.11 for compatibility with pinned packages.
